# Thorn Messenger
Данный учебный проект представляет из себя приложения для обмена сообщениями в закрытом режиме между заранее определёнными пользователями.

## О проекте
Цель данного проекта - создать средство обмена сообщениями между узким кругом лиц в приватной среде.
Данный проект является учебным, поэтому дополнительная цель - заполнить пробелы или освоить новые знания технологий и научиться вести продукт через все этапы разработки.

## Текущий статус (Последнее обновление 13.09.2026)
Проект находится в разработке.

Реализовано:
- Общая структура проекта

Планируется:
- Реализовать обмен сообщениями между пользователями
- Разработать инфраструткуру приватной сети
- Реализовать сквозное шифрование и обмен сообщениями P2P

## Установка 
Проект позиционирует себя как запускаемый из коробки, поэтому установка дополнительных программ и компонентов не треубется.

## Системные требования
Windows 10/11 с подключением к сети Интернет

## Сборка
Для сборки проекта требуется установить .NET SDK.
Проект собирается следующей командой:
```
dotnet publish -c Release -r win-x64 --self-contained true
```
